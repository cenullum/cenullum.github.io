The Pitch

cenker's mod is a multiplayer sandbox packed with 10+ ready-to-play games — from football and card games to a horror chase with him. Jump into any of them with friends online, grab more from the Steam Workshop, or build your own with Lua.

Included Games

Beyaz Canavar Campfire Survivors Crazy Eights Draw The Word Finding Liar Football Hide and Seek Hook Up MineBlockLand Operation Detonate School Days

Description

Host your own session for up to 32 players (or more for simple mods) and switch between completely different experiences: score goals, survive waves around the campfire, bluff your way through Finding Liar, draw and guess, paint yourself into the floor in Hide and Seek, or try to stay alive when Beyaz Canavar comes out of the dark.

For creators, the built-in Lua 5.4 API with an integrated Code Editor and Tile Editor handles the hard parts — automatic network synchronization, dynamic UI and 2D physics — so you can focus on the game itself.

Features

  • 10+ Included Games: Sports, card games, party, survival, horror, sandbox building and a visual novel — all in one package.
  • Online Multiplayer: Built-in Steam networking with a host-client architecture.
  • Server Browser: Lobby list with filters to find games hosted around the world.
  • Voice Chat: Integrated voice communication.
  • Steam Workshop: Discover and install new mods with a single click.
  • Make Your Own: Lua 5.4 scripting, Code Editor and Tile Editor built in.
  • Sandboxed Security: Mods run in a safe Lua environment.

About the Developer

I'm Cenker, I use Cenullum as nickname, and I have been making games since middle school. Even while studying Anesthesia in high school, I stayed committed to my hobby and went on to study Digital Game Design at university. Over the years, I have worked with engines like LibGDX, GameMaker, Unity, and Unreal.

cenker's mod is built with Godot. It was born from a desire to simplify multiplayer game development and bring people together through creativity and play.

The project started as a cross-platform prototype (Mobile, Web, PC) using AWS, but I eventually focused only on PC Steam. I realized I was rewriting the same networking code for every new game idea, so I decided to build a platform that handles that complexity once and for all.

The development took longer than I hoped. As a solo developer, I had to balance the project with various personal challenges along the way. Despite these hurdles, my passion never faded, and I kept working on the game whenever I could.
